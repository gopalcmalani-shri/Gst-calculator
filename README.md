# Gst-calculator

- `index.html` – single-page GST calculator
- [`form26as-downloader/`](form26as-downloader/) – Python tool to download Form 26AS (HTML + PDF)
- [`form26as-chrome-extension/`](form26as-chrome-extension/) – Chrome extension (HisabKitab) to download Form 26AS and send it to HisabKitab
